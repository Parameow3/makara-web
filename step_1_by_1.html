In robotics, we learnt many levels such as:

  • Lego
  • Typing

With LEGO, we learn to build creative things using imagination. LEGO bricks connect together to make cool structures.

⌨️ Typing

We learn how to type quickly and correctly using both hands. Typing helps us use the keyboard better.

💡 Microbit

We learn how to code and make sensors work using a small computer called a Microbit.

🎮 Scratch

Scratch lets us make games and animations using colorful coding blocks. It’s fun and easy to use.

🐍 Python and Pygame

We learn how to code using Python and make games using Pygame.
